# This installation

Facts about the Home Assistant installation this repository snapshots. This
file belongs to your repository: the template ships it once and never changes
it afterwards, so edit it freely.

Keep it to what helps an agent read the snapshot. Do not put hostnames, IP
addresses, credentials, or anything you would not commit in `config/`.

- **Home Assistant:** installation type (HAOS, Container, Core), version at the
  last import.
- **Where host-level notes live:** e.g. "in a separate infrastructure
  repository", so agents know not to look for them here.
- **Conventions:** naming schemes for entities, areas, and helpers; packages
  layout; anything a newcomer would get wrong.
- **Known exceptions:** findings in `reports/` that are expected and should
  not be "fixed".
- **Status:** what has been reviewed, what cleanup is in progress.
